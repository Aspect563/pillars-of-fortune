      How to join

      1. Open Minecraft Java Edition.
      2. Go to Multiplayer, then Add Server.
      3. Paste the address above and save.
      4. Hit join. If it is sleeping, it will start up.

      FAQ

      Why does the server say Sleeping?

      The server shuts down when nobody is playing. Joining with the address above wakes it up. Starting takes about a minute, so keep trying and the page will switch to Online.

      Which Minecraft edition do I need?

      Java Edition. There is no Bedrock support. The exact version shows in the Players online panel while the server is running.

      How does a round work?

      Everyone spawns on their own bedrock pillar and receives a random item every few seconds. Use the items to fight, build and survive. The last player or team standing wins.

      Where can I get help or report problems?

      Ask in the Discord. Other players and staff can help, and server news is posted there.
